# 热点数据获取模块

这个模块用于自动获取各大平台的热点数据，包括：

- 微博热搜榜
- 知乎热榜
- 百度热搜
- 今日头条热榜
- 36氪热榜
- B站热门榜单

## 功能特点

1. 多平台数据获取
2. 自动定时任务（早上8:00-10:00和中午12:00-14:00之间随机时间执行）
3. 支持JSON和CSV两种格式输出
4. 完善的日志记录
5. 反爬虫策略优化
6. 数据自动排序和分类

## 依赖安装

```bash
pip install -r requirements.txt
```

## 使用方法

1. 确保系统已安装 Chrome 浏览器
2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 运行程序：
```bash
python hot_topics.py
```

## 输出说明

程序会在 `output` 目录下生成两种格式的结果文件：

1. JSON格式：`hot_topics_YYYY-MM-DD_HH:MM:SS.json`
2. CSV格式：`YYYY-MM-DD_HH:MM:SS.csv`

### JSON文件结构：
```json
{
    "timestamp": "2024-03-21T10:30:00",
    "weibo": [
        {
            "rank": 1,
            "title": "热搜标题1",
            "platform": "weibo"
        }
    ],
    // 其他平台数据
}
```

### CSV文件结构：
```csv
platform,rank,title
weibo,1,热搜标题1
zhihu,1,热榜标题1
// ...
```

## 日志

程序运行日志保存在 `hot_topics.log` 文件中，包含：
- 任务执行时间
- 数据获取状态
- 错误信息
- 定时任务设置信息

## 注意事项

1. 程序使用 Selenium 的无头模式运行，不会打开浏览器窗口
2. 每个平台最多获取前50条热点数据
3. 如果某个平台获取失败，将返回空列表并继续获取其他平台的数据
4. 程序会在两个时间段随机选择时间执行：
   - 早上：8:00-10:00
   - 中午：12:00-14:00
5. 每次执行都会生成新的文件，不会覆盖历史数据
6. 使用随机延时和UA来避免被反爬虫机制拦截
